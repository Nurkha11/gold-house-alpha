# Защита персональных данных

## Категории данных

- идентификационные: имя, телефон, user ID;
- поведенческие: лайки, просмотры, предпочтения, рекомендации;
- недвижимость: точный адрес, координаты, документы и media;
- операционные: IP, устройство, audit events;
- чувствительные секреты: OTP, refresh tokens, service credentials.

## Принципы

1. Собирать только данные, необходимые конкретной функции.
2. Разделять публичное представление объекта и приватные данные владельца.
3. Не помещать секреты и точные координаты в клиентский bundle, analytics или обычные логи.
4. Проверять доступ на backend при каждом запросе.
5. Устанавливать срок хранения и автоматическое удаление для каждого класса.
6. Поддерживать экспорт, исправление и удаление данных пользователя.

## Хранение и передача

- TLS для всех соединений;
- шифрование дисков/managed database;
- field-level encryption или tokenization для телефона и точной локации, если требует модель угроз;
- hash refresh tokens и OTP;
- секреты в secret manager, не в `.env` репозитория;
- резервные копии шифруются и имеют отдельную политику доступа.

## Клиент

- access token только в памяти;
- refresh token: HttpOnly cookie на web, secure storage на mobile;
- никакой персональной информации в URL query;
- очищать state/cache при logout;
- `EXPO_PUBLIC_*` считать публичным;
- analytics получает псевдонимные ID и allowlist событий.

## Логи и аудит

Логи редактируют телефон, OTP, токены, точный адрес и содержимое документов. Audit log хранит факт доступа/изменения, но не полную копию секрета. Доступ к audit — отдельное разрешение.

## Retention

Конкретные сроки требуют юридического и продуктового решения. До него должны существовать конфигурируемые политики для OTP, sessions, незавершённых заявок, audit, media и удалённых аккаунтов. Удаление выполняется также из поисковых индексов, очередей и по политике backup expiration.

## Инциденты

Процесс должен включать отзыв сессий, ротацию секретов, блокировку интеграции, сохранение доказательств, оценку затронутых пользователей и уведомление ответственных лиц.
