# Обзор Gold House

Gold House Alpha — клиентский MVP помощника по подбору недвижимости. Покупатель задаёт фильтры, оценивает квартиры и получает три персональные рекомендации с объяснениями. Отдельный поток позволяет собственнику подготовить объявление, а клиентская «админка» — просмотреть и изменить его статус.

## Пользователи

- покупатель;
- собственник объекта;
- администратор/модератор.

## Фактически реализовано

- профиль покупателя и гостевая сессия;
- фильтры: Алматы, районы, бюджет, комнаты и категория этажа;
- обучение на лайках/дизлайках и иных сигналах;
- карточки, детальный экран, похожие квартиры;
- сохранённые действия и рекомендации в кабинете покупателя;
- макет записи на просмотр и звонок;
- вход собственника без реальной аутентификации;
- девятишаговая подача объявления, черновик и статусы;
- клиентская административная панель;
- адрес, ЖК, предупреждения геолокации и web-интеграция Yandex Maps.

## Статус

Это демонстрационный клиентский прототип. Backend, серверная аутентификация, реальная запись на просмотр, уведомления, платёжные функции и production-модерация отсутствуют. Каталог состоит из 69 локальных тестовых объектов плюс опубликованные в текущей JS-сессии заявки.

## Основной путь покупателя

`/` → `/buyer-profile` → `/city` → `/district` → `/rooms` → `/budget` (переход зависит от экрана района) → `/floor` → `/ai-loading` → `/swipe` → `/ai-analysis` → `/personal-recommendations` → `/property/[id]` → `/viewing` → `/confirmed`.

Некоторые переходы обходят бюджет: фактическую схему следует смотреть в [SCREENS.md](SCREENS.md).
