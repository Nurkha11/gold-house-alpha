# Архитектурные решения

| Решение | Наблюдение | Причина |
|---|---|---|
| Expo + React Native + web | Единая кодовая база и Expo Router | Причина не зафиксирована |
| Файловые маршруты | `app/` и `expo-router/entry` | Явно следует из конфигурации |
| Локальные данные | `data/properties.ts`, in-memory stores | MVP без backend; точная причина не зафиксирована |
| Эвристические рекомендации | Веса и фильтры в `aiTrainingStore.ts` | Причина не зафиксирована |
| Мягкий бюджет | Бюджет влияет на score, не hard filter | Причина не зафиксирована |
| Yandex Maps только web | JS API загружается через `window` | Технически следует из реализации |
| Приблизительная публичная локация | `publicLocationPrecision: approximate` | Предположительно приватность; требует подтверждения |
| Buyer snapshot в истории | События сохраняют характеристики объекта | Стабильность истории следует из структуры |
