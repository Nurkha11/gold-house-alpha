# Yandex Maps

## Реализация

- `components/YandexPropertyMap.tsx` динамически загружает Yandex Maps JavaScript API 2.1.
- Ключ читается из `EXPO_PUBLIC_YANDEX_MAPS_API_KEY`.
- `OwnerLocationPicker` использует `ymaps.suggest` и `ymaps.geocode`.
- Маркер можно поставить кликом и перетащить.
- Локальный справочник ЖК и проверки дублей находятся в `data/residentialComplexes.ts`.

## Платформы

Настоящая карта работает только в браузере. На iOS/Android компонент показывает сообщение о недоступности; нативный SDK или WebView не реализованы.

## Fallback

При отсутствии ключа адрес можно вводить вручную. Присваивается источник `manual`, а модератору показывается предупреждение. Это не реальная геокодировка.

## Риски

- публичный Expo env-ключ неизбежно доступен в клиентском bundle; его необходимо ограничить на стороне Yandex;
- поиск и геокодирование зависят от браузера и сети;
- район при ручном вводе определяется простой эвристикой;
- при выборе точки создаётся условный текст адреса без reverse geocoding;
- native-карта отсутствует.

Секретные значения в документации не приведены.
