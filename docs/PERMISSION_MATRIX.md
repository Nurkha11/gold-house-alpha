# Матрица разрешений

Обозначения: `Own` — только собственные ресурсы; `Scoped` — только назначенная область; `All` — все ресурсы соответствующего типа.

| Ресурс / действие | Buyer | Owner | Admin | System |
|---|---:|---:|---:|---:|
| Читать/менять свой профиль | Own | Own | Scoped read | Нет |
| Удалить свой аккаунт | Own | Own | Нет | Scheduled purge |
| Читать публичные объекты | Да | Да | Да | Да |
| Создать объявление | Нет | Own | Нет | Нет |
| Читать черновик объявления | Нет | Own | All | Нет |
| Изменить черновик | Нет | Own | Нет | Нет |
| Отправить на модерацию | Нет | Own | Нет | Нет |
| Отозвать до проверки | Нет | Own, по workflow | Нет | Нет |
| Менять moderation status | Нет | Нет | Scoped | Нет |
| Публиковать/скрывать объект | Нет | Нет | Scoped | Нет |
| Менять владельца объекта | Нет | Нет | Только super_admin + audit | Нет |
| Сохранить объект | Own | Own как buyer | Нет | Нет |
| Создать заявку на просмотр | Own | Own как buyer | Нет | Нет |
| Читать заявку на просмотр | Own | Для своего объекта, минимум данных | Scoped | Для доставки |
| Подтвердить/предложить время | Нет | Для своего объекта | Scoped override | Нет |
| Отменить просмотр | Own | Для своего объекта | Scoped | Нет |
| Читать точный адрес | По политике показа | Own | Scoped | Только доставка |
| Читать телефон другой стороны | После разрешённого этапа | После разрешённого этапа | Scoped | Только доставка |
| Управлять ролями | Нет | Нет | Только super_admin | Нет |
| Читать audit log | Нет | Нет | Scoped/security admin | Append only |

## Правила реализации

1. Проверка выполняется в backend service/repository layer для каждого запроса.
2. `user_id`, `owner_id`, `buyer_id` не принимаются как доверенные полномочия из body; субъект берётся из токена.
3. Изменение статуса выполняется отдельной командой, а не произвольным PATCH.
4. Ответы используют DTO и исключают поля, не разрешённые роли.
5. Любая административная мутация содержит `actor_id`, причину и audit event.
6. Отказ возвращает `403`; отсутствие чужого приватного ресурса может маскироваться как `404`.
